🧠 LLM Pipeline Architecture Guide

1. Tokenization (BPE)

Raw text cannot be understood directly by neural networks. The tokenizer breaks strings into subwords or byte sequences. Each subword maps to a discrete integer token ID in a predetermined vocabulary dictionary (e.g., 50,257 tokens in GPT-2/3).

2. 3D Vector Embeddings & Positional Encoding

Each token ID indexes a high-dimensional lookup matrix W_e ∈ R^{V×d}. Semantically related concepts occupy nearby vector coordinates. Because transformer attention is permutation-invariant, a sinusoidal positional wave PE(pos,2i) = sin(pos / 10000^{2i/d}) is added to inject word order.

3. Multi-Head Self-Attention

Each token projects into Query (Q), Key (K), and Value (V) vectors. Dot products compute how much focus every token should direct toward other words. Causal masking ensures tokens cannot peek into the future.

4. Logits, Softmax & Next Token Sampling

The final layer transforms hidden vectors back to vocabulary dimension logits. A temperature-adjusted softmax converts logits into a valid probability distribution P(w_i). The model samples the most coherent next token to continue the sentence.
